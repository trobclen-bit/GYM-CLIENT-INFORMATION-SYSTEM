Gym Client Information System

Simple PHP PDO OOP Version

1. Copy this folder into C:\xampp\htdocs\
2. Start Apache and MySQL.
3. Open http://localhost/phpmyadmin
4. Import database/clenuar_gym_client.sql
5. Open http://localhost/clenuar_gym_client/

Flow: Form -> handler.php -> Client object -> PDO query -> MySQL -> index.php

Note: This simple version directly follows the Clients entity in the Prelim ERD: ClientID, FirstName, LastName, Gender, BirthDate, ContactNumber, Address, and Email.
